The brain: url2brain

Open source. Self-hostable for free. Also sold as a metered API for AI agents.

All of the reading, writing and publishing above is done by url2brain, a standalone open-source FastAPI service — the same code, MIT-licensed on GitHub, that you can self-host with your own local LLM (Gemma 4 12B via Ollama) for zero marginal cost. This website is one client of it; AI agents can be another.
